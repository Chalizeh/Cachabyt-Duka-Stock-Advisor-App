# 10-Minute Class Presentation

1. **Problem (2 min):** Explain canteen queues, stock-outs and student break-time pressure.
2. **Live application (3 min):** Show stock, record a sale, low-stock warning and student order.
3. **AI memory (2 min):** Run at least four turns; show how earlier turns inform later answers.
4. **Technical explanation (2 min):** Explain local JSON memory, Gemini API, JSON checks and session saving.
5. **Questions (1 min):** Invite questions from the class.

Every group member must speak. The assignment requires a live demonstration of a four-turn session, a saved session file and one deliberate failure test.
